# Expense Tracker

Personal Finance Management System — Backend REST API.

## Tech Stack
- Java 21
- Spring Boot 3.x
- Spring Data JPA + Hibernate
- MySQL
- Flyway
- Spring Security + JWT
- Maven

## Setup
1. Copy `.env.example` to `.env` and fill in your local values.
2. Create MySQL database `expense_tracker`.
3. Run: `mvn spring-boot:run`

## API
Base path: `/api/v1`
